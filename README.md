# 🤖 Artificial Intelligence in Software Engineering

## Overview

This repository documents my journey integrating AI tools (like Gemini and ChatGPT) into software engineering workflows. Each task folder contains:

- **Initial code** - My original implementation
- **Final code** - AI-refactored/improved version
- **Documentation** - The story of our collaboration
- **Prompts** - Screenshots or logs of AI conversations

The goal is to demonstrate not just the final product, but the **process** of using AI responsibly and effectively.
